# XWAIFUPHISHER

# INSTALLATION


## KALI

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/rxndnce/xwaifuphisher.git

2. **Navigate to the Project Directory:**
   ```bash
   cd xwaifuphisher

3. **Install Required Packages:**
   ```bash
   sudo apt-get install php curl ssh jp2a unzip

4. **Usage**:
   ```bash
   bash xwaifuphish.sh
